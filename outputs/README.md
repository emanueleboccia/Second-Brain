# Outputs

**I deliverable prodotti: la roba finita che esce da qui e va a qualcuno.**

Ci vanno preventivi, proposte in PDF, fatture, report e presentazioni. Una cartella per
tipo, come `preventivi/` che esiste già.

## Cosa distingue outputs/ dal resto

Un file in `outputs/` è **una cosa consegnata o consegnabile**, con una data e un
destinatario. Non è una nota, non è una regola, non è materiale di lavoro: è il risultato.

- Il **metodo** con cui si costruisce un preventivo sta in `docs/`.
- I **prezzi** stanno in [[self/tariffario|tariffario]].
- Lo **stato** di una proposta — inviata, accettata, ferma — sta su Notion.
- Il **file finito** sta qui.

## L'area finanza li richiama, non li duplica

`areas/finanza/` ragiona sui numeri e cita la fonte. Quando un'analisi finanziaria parla
di una fattura o di un preventivo, **linka il file che sta qui**: non ne ricopia gli
importi in una tabella parallela che alla prima correzione diverge dall'originale.
