# Libri

Un file per libro: `titolo-breve.md`.

In testa al corpo va la riga **DOVE MI SERVE** con i wikilink alle aree in cui quel libro
cambia qualcosa. Poi le idee che si usano, non il riassunto dei capitoli.

Se di un libro resta una sola idea buona, la nota ha una sola idea. È il formato giusto.
