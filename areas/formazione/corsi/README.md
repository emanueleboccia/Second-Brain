# Corsi

Una cartella per corso, `nome-corso/`, e dentro un file per modulo o lezione:
`01-titolo-modulo.md`.

Il numero davanti serve a tenere l'ordine del corso senza doverlo ricostruire a mente.
In testa a ogni modulo va la riga **DOVE MI SERVE**.

Il corso di copywriting e gli altri stanno oggi su TickTick e su Notion: si portano qui i
moduli che servono davvero, uno alla volta.
