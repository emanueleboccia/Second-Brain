# Routine mattutina

Prima di iniziare a lavorare serve una routine energizzante: negli appunti, allenamento o lettura
degli obiettivi. La regola è **non sedersi mai alla scrivania scarico o demotivato**, perché
l'entusiasmo è il motore delle chiamate.

Non è motivazione generica. È un requisito tecnico: la prima cosa che il cliente percepisce è
[[docs/vendita/tono-di-voce|il tono di voce]], e un venditore scarico suona come un operatore di
call-center. Il set mentale del mattino è quello che rende sostenibile riempire ogni buco con
[[docs/vendita/tempi-morti|una chiamata a freddo]].

È il capo opposto della giornata rispetto al
[[docs/vendita/report-serale|report serale]]: si apre col set mentale, si chiude con i numeri.
