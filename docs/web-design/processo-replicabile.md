# Processo replicabile, non opera d'arte

Gli appunti insistono su un punto: costruire un **processo ripetibile** ed evitare il paradigma
dell'opera d'arte. Per le attività locali conta avere qualcosa di buono, veloce, replicabile e
orientato al risultato.

L'obiettivo è **poter produrre tanti siti o landing in sequenza con un framework stabile**,
invece di reinventare ogni volta una soluzione creativa complessa.

Il principio scende in tre posti concreti:

- [[docs/web-design/stili-come-strutture-mentali|Gli stili]] evitano di ripartire da zero su
  colori, font ed emozioni per ogni cliente.
- [[docs/web-design/modelli-di-hero|I modelli di hero]] evitano di inventare una sezione d'entrata
  a ogni progetto.
- [[docs/web-design/processo-in-cinque-step|I cinque step]] danno l'ordine in cui si lavora, così
  quando ci si blocca si sa qual è il passo successivo.

La personalizzazione si mette **dove porta valore reale**, non ovunque per simmetria.
