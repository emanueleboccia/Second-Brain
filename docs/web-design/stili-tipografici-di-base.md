# Gli stili tipografici di base

La checklist operativa degli appunti, da fare **prima** di cominciare a impaginare.

- Definire subito stili coerenti per **H1, H2, H3, H4 e H5** — H6 se serve.
- Almeno **uno stile di corpo**, cioè di paragrafo.
- **Uno stile per i bottoni.**

Con questi quattro elementi — headline, corpo, bottoni, più le gerarchie che li legano — si hanno
le basi grafiche del sito. Aggiunti i colori, il brand kit e il
[[docs/web-design/wireframe|wireframe]], costruire le pagine diventa molto più semplice.

È il modo in cui la tipografia smette di essere una decisione ripetuta a ogni sezione e diventa
un'impostazione: agganciato uno stile a ogni livello di headline, non si ristilizza ogni volta.
Con [[docs/web-design/unita-di-misura|rem]] si può poi cambiare la scala di tutto il sito da un
punto solo.

È lo stesso principio di [[docs/web-design/processo-replicabile|processo replicabile]] applicato
alla tipografia: decidere una volta, riusare sempre.
