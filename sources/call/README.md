# Call — trascrizioni grezze

Le trascrizioni delle call, prese da **Granola**. Un file per call:
`AAAA-MM-GG-interlocutore.md`.

## Regola unica

**Questi file non si modificano mai.** Sono la registrazione di cosa è stato detto, non
un documento di lavoro. Correggerli, riassumerli o riordinarli vuol dire perdere l'unica
cosa per cui esistono: essere una fonte che nessuno ha ritoccato.

Quello che serve si estrae e si scrive **altrove** — nello `storico.md` del cliente, in
una nota di progetto, in una decisione — e da lì si **linka** qui con un wikilink.

`sources/` sta fuori dal gate di qualità e fuori da `llms.txt`: qui non serve
frontmatter, e nessuno viene a controllare quanti collegamenti ci sono.
