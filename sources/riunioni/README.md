# Riunioni — trascrizioni grezze

Le trascrizioni delle riunioni: Sistema Evolve, i tre brand di famiglia, i clienti.
Un file per riunione: `AAAA-MM-GG-argomento.md`.

Vale la stessa regola delle call: **non si modificano mai**, e si richiamano via wikilink
da dove serve. Quello che è stato deciso in riunione va scritto nella nota che lo riguarda
— non lasciato dentro la trascrizione, dove nessuno andrà a cercarlo.

La differenza con `sources/call/` è chi c'è dentro: una call è con una persona, una
riunione è con un gruppo, e in un gruppo conta anche chi ha detto cosa.
