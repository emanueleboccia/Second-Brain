# Assets del journal

Qui dentro va `sigla.mp3`, se e quando esisterà: la musica che il comando «buongiorno audio»
mette sotto la voce. Apre da sola per due o tre secondi, scende quando entra la voce, risale in
coda.

Finché il file non c'è, il briefing audio esce a voce sola e non lo segnala: un avviso che si
ripete ogni mattina per una cosa che non è un problema diventa rumore.

Il mix si fa con ffmpeg, che va installato a parte.
