# Review settimanale

Un file per settimana: `AAAA-Wnn.md`, per esempio `2026-W36.md`.

Si copia `_template.md` e si risponde a quattro domande. Non è un riassunto della
settimana — quello sta già nel journal — ed è per questo che le domande sono scomode.

`workspace/` sta fuori dal gate di qualità e fuori da `llms.txt`.
